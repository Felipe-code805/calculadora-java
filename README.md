# Calculadora Java

Projeto desenvolvido em Java como parte dos meus estudos de programação, com o objetivo de praticar lógica de programação, métodos, estruturas condicionais, estruturas de repetição, validação de entradas e utilização da classe Scanner.

## Funcionalidades

- Soma de dois números
- Subtração de dois números
- Multiplicação de dois números
- Divisão com validação para evitar divisão por zero
- Cálculo de potência
- Cálculo de raiz quadrada
- Cálculo da média de múltiplos números
- Validação de entradas numéricas
- Menu interativo pelo terminal
- Verificação de aprovação ou reprovação com base na média informada

## Tecnologias utilizadas

- Java
- Java Scanner
- Math API
- Git
- GitHub

## Conceitos praticados

- Variáveis e tipos de dados
- Métodos
- Estruturas `if/else`
- Estrutura `switch`
- Estrutura `do/while`
- Estrutura `for`
- Validação de entrada
- Manipulação de números
- Organização e reutilização de código

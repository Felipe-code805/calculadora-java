# Calculadora Java

Projeto desenvolvido em Java como parte dos estudos de programação, com o objetivo de praticar lógica de programação, métodos, estruturas condicionais, estruturas de repetição, validação de entradas e utilização da classe Scanner.

## Funcionalidades

* Soma de dois números
* Subtração de dois números
* Multiplicação de dois números
* Divisão com validação para evitar divisão por zero
* Cálculo de potência
* Cálculo de raiz quadrada
* Cálculo da média de múltiplos números
* Validação de entradas numéricas
* Verificação de aprovação ou reprovação com base na média
* Menu interativo pelo terminal

## Tecnologias utilizadas

* Java
* Scanner
* Math

## Conceitos praticados

* Variáveis e tipos de dados
* Métodos
* Estruturas `if/else`
* Estrutura `switch`
* Estrutura `do/while`
* Estrutura `for`
* Validação de entrada
* Manipulação de números
* Organização e reutilização de código

## Como executar

### Pré-requisitos

* Java JDK instalado

### Compilação

```bash
javac Calculadora.java
```

### Execução

```bash
java Calculadora
```

## Exemplo de uso

Ao iniciar o programa, é exibido um menu com as opções disponíveis:

```text
[1] Soma
[2] Subtração
[3] Multiplicação
[4] Divisão
[5] Potência
[6] Raiz quadrada
[7] Média
[0] Sair do sistema
```

O usuário seleciona uma operação e informa os valores necessários. Na opção de média, é possível informar a quantidade de números que serão utilizados no cálculo. Ao final, o programa informa se a média é suficiente para aprovação, considerando média igual ou superior a 7.
